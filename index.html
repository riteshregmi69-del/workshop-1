Welcome to StudySpace

StudySpace is a simple learning resource platform designed to help students find useful academic materials, tutorials and study resources in one place.

Whether you are preparing for your weekly lab workshops, reviewing lecture slides, or learning fundamental programming concepts, StudySpace brings key academic materials together to support your university coursework.

Study Resources

Here is a collection of essential academic materials and recommended external documentation.

Academic Materials

  • Lecture Notes: Weekly PDF lecture slides and presentation handouts.
  • Practical/Lab Materials: Step-by-step tutorial worksheets and starter files.
  • Assignment Guides: Coursework briefs, marking schemes, and submission criteria.
  • Programming Tutorials: Hands-on guides for HTML, CSS, JavaScript, and Python.
  • Exam Preparation: Past exam papers, revision checklists, and sample solutions.
  • Recommended Books: Textbook recommendations available at the campus library.

Recommended Educational Links

Bookmark these trusted external resources for extra study:

  • MDN Web Docs - Standard web documentation for HTML and CSS.
  • W3Schools - Beginner-friendly web development examples and exercises.
  • Python Documentation - Official documentation and tutorials for Python.
  • Khan Academy - Free video courses in mathematics and computer science.
